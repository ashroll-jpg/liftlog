  1. Create a GitHub token. It opens with only gist checked. Set Expiration to No expiration, tap Generate token, and copy it.
    2. 
        
  2. Paste it here and tap Connect.
    3. 
        
  3. Do the same on your other device. Use the same token, or make a second one.
    4.
